## Design Specificity Verdict

**Start here.** 结果是为「七卷拾光」写的，不是类别互换模板。

**LLM assessment**：空厅的两字碑「拾光」、底边提问线、聚焦时从左生长的金线、七词、圆印回厅、货架才出卡片——这套组合绑在维护者的公开书签目录上。拉丁眉题 `BIBLIOTHECA`、轨道圆、页脚题签偏档案套装，换馆也能成立；但厅/架分工和金线提问是这个产品自己的。

**Deterministic scan**：CLI `detect.mjs --json index.html` 因缺少 htmlparser2/css-tree **降级为 regex**，exit 0、JSON `[]`，这是 undercount，不是干净。浏览器注入 `detect.js` 后：空厅 9 条、货架 16 条、厅内检索 `mdn` 12 条。真实命中：`.paper-toggle` 9px `undersized-ui-text`；货架分组标题 10px；`.tagline` / `.footer-row` / `.hall-item-meta` 的 `wide-tracking`；厅内 `hero-eyebrow-chip`（`BIBLIOTHECA`）。假阳性：`dark-glow` 其实是品牌印 1px 金环（blur=0）；隐藏的厅/架 DOM 重复计数；`text-overflow` 是题名索引 ellipsis 的预期 `scrollWidth`。

`wide-tracking`、眉题、9–11px 印戳与 DESIGN.md 的 Archive Paper 纪律一致（brief wins）。真正要处理的是 9px「夜间」不可读，以及触控/短视口把说明书和决策面挤掉。

## Overall Impression

空厅是一张有记忆点的纸：碑落下，金线等提问。Operate 的失败发生在用户开始干活之后——提问时碑仍占半屏，索引溢出；手机把唯一说明书藏掉；无匹配却被请去看空货架。最大机会：让提问态和触控态把决策面交给索引/货架，空厅仍做大碑。

## What's Working

1. **空厅是有性格的一屏。** 圆印 + 字标 → 眉题 → 拾光 → 耳语 → 底边线 → 七词，厅内没有卡片网格，金线从左生长对得上 north star。
2. **同一张纸翻到夜里。** `data-paper` 换色板不换 DOM；金只作线、点、环；货架卡片是落在纸上的 sheet。
3. **给会用的人的捷径是真的。** `/` 聚焦、方向键选题名、选中金点、题名保持墨色、约束可叉。

## Priority Issues

### [P1] 提问时碑仍占半屏，索引在桌面溢出
- **Why it matters**：输入后索引才是主任务决策面。1440×900 上 `scrollHeight` 1006 / `vh` 900，末行贴折线。DESIGN 写「厅内不为卡片网格纵滚」「索引最多约七行」，七行却放不进那一屏。
- **Fix**：提问态把 `.site-main` 上内边距从 14.3125rem 收成区块尺度，碑留在原位但降到字标级；短视口/横屏同样让出高度。
- **Suggested command**：`/impeccable adapt`

### [P1] 移动端关掉了唯一说明书，也没有可发现的全部货架入口
- **Why it matters**：`.hints` 在 `(pointer: coarse), (max-width: 47.99rem)` 为 `display: none`。390 上看不到「↵ 进入货架」。七词无底无边，像题签不是按钮。空回车进 `/shelf` 全靠记。
- **Fix**：触控/窄屏用一句中文替代键位，不要整组藏掉；触控下给七词可感知的底边；不要把核心路径藏起来。
- **Suggested command**：`/impeccable adapt`

### [P1] 「厅内无题名。回车到货架上看。」是假承诺
- **Why it matters**：死查询回车走 `resolveHallSubmit` → 货架「没有匹配的书签 / 0 个站点」。错误态多一步，还暗示会看见结果。
- **Fix**：无匹配回车应去无约束货架，或改耳语说明「没有这道题 / 回车看全部」。
- **Suggested command**：`/impeccable clarify`

### [P2] 「夜间」不是一个能被找到的控件
- **Why it matters**：9px、`letter-spacing: 0.2em`、`gold-dim` 白日对比约 2.78:1。Detector 记为 `undersized-ui-text`。唯一换纸开关在最需要时最看不见。
- **Fix**：窄屏/触控至少 11px，颜色用墨或灰；金留给悬停/焦点。保留页脚，不放到 Logo。
- **Suggested command**：`/impeccable adapt`

### [P2] 货架卡片被 44px 标签撑开；提问行滚走就丢
- **Why it matters**：`.card-tag { min-height: 44px }` 把短卡撑出空皮。`#shelf-form` / `#constraints` 不吸顶，改提问必须先滚回顶。
- **Fix**：标签视觉紧凑、热区用扩展伪元素；提问行与「已约束」跟顶栏一起吸顶。
- **Suggested command**：`/impeccable adapt`
