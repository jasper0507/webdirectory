## Overall Impression

空厅仍然是一张有记忆点的纸：碑落下，金线等提问。上一轮的几处 P1（触控提示被藏、无匹配送进空货架、卡片标签 44px 撑皮、货架提问行滚走）已经对上规格。Operate 现在的裂缝改到两处：短横屏/短视口还不肯结束典礼，索引掉到折线下；金被拿去写「清除约束 / 重新加载」，日间读不成字。最大机会：提问态把视口还给索引，恢复动作还给墨。

## What's Working

1. **空厅是有性格的一屏。** 1440×900 与 390×844 均 `scrollHeight === innerHeight`。圆印 + 字标 → 眉题 → 拾光 → 耳语 → 底边线 → 七词，厅内没有卡片网格，金线从左生长对得上 north star。
2. **厅/架物质分界清楚。** 进架碑消失、星尘隐藏、卡片落在 sheet 上、2px 发丝边悬停改金不抬起；回厅清空提问、收起索引、焦点不粘在输入上。少命中时卡片不撑满，页脚沉底。
3. **给会用的人的捷径是真的。** `/` 聚焦、方向键 + `aria-activedescendant`、选中金点、题名保持墨色、唯一题名回车打开、无匹配回车进无约束货架、窄屏改中文提示且不整组藏掉。

## Priority Issues

### [P1] 短视口提问态：索引不在视口里
- **Why it matters**：Operate 的成功标准是尽快找到并打开。844×390 上列表 bottom 571 / 视口 390，只露出「标签 / 文档 / 题名」，题名行在折线下。667×375 空厅已溢出 153px。问完却先看见碑和耳语，是任务失败。
- **Fix**：`max-height: 48rem` 以及 `is-asking` 下收起或大幅压缩 `.overline`、`.tagline`、`.hints`，碑收到一行字标尺度；保证 `#hall-list` 底边落在视口内。不要只减 `padding-top`。
- **Suggested command**：`/impeccable adapt`

### [P1] 日间金色文字达不到可读对比
- **Why it matters**：`--color-gold #a87b3f` 叠 `--color-ink #eef0f2` = **3.30:1**。`.text-action`（「清除约束」「重新加载」）12px 字。夜间金/纸 4.43，仍低于小字 4.5。失败恢复是 Operate 的高风险点，最需要的按钮看起来像装饰。检测器因 regex 降级没评对比度。
- **Fix**：金继续只做线、点、环。恢复动作改用墨色字 + 金线，或把字号抬到大文本门槛。不要把金字加深成「另一块金」。
- **Suggested command**：`/impeccable harden`

### [P2] 同一回车四种结局，键入标签 ≠ 选中标签
- **Why it matters**：选中题名打开、无选中且唯一打开、选中标签进 `tag=`、否则带 `q=` 进架。键入「文档」直接 Enter → `/shelf?q=文档`；方向键选中「文档」再 Enter → `/shelf?tag=文档`。索引第一行就是标签，默认回车却当模糊词。
- **Fix**：若 query 与唯一/首行标签名相同，无选中也走 `tag=`；或默认高亮第一行。提示改成「↵ 打开高亮项」。
- **Suggested command**：`/impeccable clarify`

### [P2] 卡片标签不像可点约束
- **Why it matters**：`.card-tag` 视觉约 29×20、11px 灰、无边无底；`::before` 外扩后约 49×42。Casey 会当成废字；误触又会改约束。已约束才有金线。
- **Fix**：保持印戳字级，给未约束标签一条待命短金线（厅内七词在 `hover: none` 上已有短线）。热区至少 44px 高，不要只靠看不见的伪元素。
- **Suggested command**：`/impeccable layout`

### [P2] 加载失败长得像空货架
- **Why it matters**：`showLoadError` 藏厅、亮架，搜索行和「0 个站点」仍在，重试是 12px 金字。空目录同壳。用户会先去搜，而不是重试。
- **Fix**：失败态不要复用货架壳：去掉提问行和「0 个站点」，把原因和「重新加载」做成主列唯一内容，动作用墨。
- **Suggested command**：`/impeccable harden`
