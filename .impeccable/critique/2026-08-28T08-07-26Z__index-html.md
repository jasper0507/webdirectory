## Design Specificity Verdict

**判定：authored。** 这不是换皮导航站。

**LLM assessment：** 空厅是一张浅档案纸上的题签——圆印、字距拉开的「七卷拾光」、金点「SEVEN SHELVES · 七卷同归」、眉题 BIBLIOTHECA、两字碑「拾光」、两行耳语、一根底边提问线加金描边圆钮、无框七词。货架不复制碑。夜间是同一张纸翻过去，金仍是 `#a87b3f`。可原样搬到无关产品上的零件很少：放大镜圆钮，以及圆印角上不在金律里的 `#d97757` 赤陶。北星在空厅几乎满分；一提问，构图裂开。

**Deterministic scan：** CLI 对 `index.html` 报 exit 0、0 条，但这是漏检：缺 `htmlparser2 / css-select / css-tree / domutils`，HTML 引擎 DEGRADED，自定义属性、选择器、计算对比度都没评。`src/ui.ts` 同样 0 条（生成 DOM 对静态扫描不可见）。扫 `src` 得到 **exit 2、15 条，全部 `design-system-font-size`，全在 `src/styles.css`**。浏览器注入后页内规则是 `hero-eyebrow-chip`、`wide-tracking`、`dark-glow`、货架上 `undersized-ui-text`×7。

对照 DESIGN.md 正文（不是 YAML 那四档），下列是**误报**：BIBLIOTHECA 眉题、耳语 `0.18em`、字标 / 页脚宽字距、提交钮悬停金尘光晕、Label 9–11px、耳语 13px。YAML sidecar 只收了 `7.5rem / 1.12rem / 16px / 10px`，检测器按这份残阶打，不等于实现跑偏。真正偏离正文阶的是：厅内题名 `14px`、结果句 `0.88rem`、卡片描述 `0.9rem`、URL `0.8rem`、空态标题 `1.5rem`。货架分组「文档 · 11」等 `10px` 落在 9–11px 规格内，但作为功能文案偏瘦——检测器在这里和 LLM 的「影子控件」判断同向。

检测器没看见、评审看见的：厅内 autofocus、唯一题名 Enter 进货架、回厅残留查询、金叉热区、白日金 3.30:1（parser 退化所以对比度未扫）、圆印赤陶、提问态一屏被撑破。

**Visual overlays：** 注入成功，detector 在厅、带查询的厅、货架、`?q=github`、夜间纸上执行过，标题含 `[Human]`。评估会话已关闭，**当前没有仍打开的覆盖层标签页**。

## Overall Impression

空厅已经像一个产品，不像一套模板。Operate 的伤口不在「找不找得到」，而在「问」之后：碑不让位，命中是页上最瘦的字；约束不像能点的东西；打完唯一题名还要再 ArrowDown。把提问态当成第二构图来做，这页会从「漂亮的厅」变成「能用的厅」。

## What's Working

1. **空厅是真正的题签。** 碑、耳语、发丝提问线、无框七词、卡片缺席——Archive Paper 的北星在桌面白日 / 夜间都站得住。
2. **提问词与精确标签是两条通道，不是一层滤镜。** 七词进 `?tag=`，选中题名回车打开 URL，空回车进全货架；货架再叉、再叠，结构清楚。
3. **夜间是同一张纸。** `data-paper` 换色板不换 DOM，金不改成漆，卡片只出现在货架。

## Priority Issues

### [P1] 厅内满编索引撑破一屏题签
- **What：** 输入后标签 + 题名约 7 行时，桌面 1440×900 上七词和页脚被顶出视口；「github」一问，碑仍占半屏，命中 14px 贴在折线附近。
- **Why it matters：** Operate 的「看见命中」发生时，构图还在演空厅仪式。用户要的是打开站点，不是再看一次「拾光」。
- **Fix：** 提问态收碑或减顶垫，把索引锁在提问线与页脚之间；满 7 行不得把页脚顶走。
- **Suggested command：** `/impeccable layout`

### [P1] 回厅不清提问，且一进厅就抢走阅读顺序
- **What：** Logo「回到拾光」后 URL 是 `/`，`#q` 仍是上次查询，索引展开、七词变淡。`renderHall` / 厅路由必 `ui.search.focus()`；`/` 在已聚焦的输入里会打出斜杠。
- **Why it matters：** 题签被上次检索占住；skip link、「/」、金线入场都失去意义。高峰在看碑，动画在看碑之前就演完。
- **Fix：** 回厅清空 `#q` 并收起 listbox；不要默认 autofocus，让 `/` 和「跳到提问」真正工作；金线等用户聚焦再生。
- **Suggested command：** `/impeccable harden`

### [P1] 金叉 / 共现 / 卡片标签不像能点的约束
- **What：** 「提问 · Playwright ×」「存档 ×」无填充无描边，× 约 7×15px；共现词像一行灰字；卡片「文档」宽约 29px。货架分组「文档 · 11」是 10px 功能字。
- **Why it matters：** 进货架之后的主操作是收窄和撤销。现在这三件事都长得像说明文字。
- **Fix：** 保持无填充，但让 × 成为 ≥24px 金热区；约束行加一句极小的「已约束」；卡片标签悬停金线，并与「打开」分区。
- **Suggested command：** `/impeccable clarify`

### [P2] 唯一题名命中，Enter 仍进货架
- **What：** 打完精确标题，索引里就一条；不 ArrowDown 再 Enter，提交处理器走 `go(shelfPath(ui.search.value))`。
- **Why it matters：** 维护者打开已知站点多一屏。kbd 写了双义，主任务却是打开 URL。
- **Fix：** 无选中且唯一题名时 Enter 打开；或默认高亮第一行。标签行仍进货架。
- **Suggested command：** `/impeccable distill`

### [P2] 白日金字 3.30:1，圆印另有赤陶
- **What：** 选中题名、检索图标、金叉都是 `#a87b3f` on `#eef0f2`（夜间金约 4.43，仍略欠 4.5）。`favicon.svg` 角标 `#d97757`，对比约 2.73:1，是第二强调色。
- **Why it matters：** 选中态对低视力不够；「金是唯一强调」被赤陶打断。
- **Fix：** 选中用金线 / 金点而不是整行金字；圆印改金或改墨。
- **Suggested command：** `/impeccable colorize`

## Persona Red Flags

**Alex（不耐烦的维护者）：** 打知名标题应一次打开。现在输入 → 看见一行 → Enter 却进货架。厅已 focus，`/` 插入斜杠。回厅还带着上次查询。无约束货架要扫「文档 · 11」。

**Sam（键盘 / 读屏 / 低视力）：** 进厅焦点已在 `#q`，跳过 skip 与两字碑。七词是 `button` 兼 `role="listitem"`。约束钮名叫「文档」不是「移除文档」。选中只变金（3.30:1）。提问框 `outline: none`，和圆钮共用 `focus-within` 金线，分不清焦点在输入还是提交。

**Casey（单手移动）：** 七词折成 5+2，卡片标签宽约 29px，易误触打开。货架「夜间」在长列表底。`.hints` 在粗指针 / 窄屏隐藏，不知道 Enter 双义。Sticky 顶栏无 `scroll-padding`，回滚时标题可被裁进「七卷拾光」。

## Minor Observations

- `text-action`（清除约束）规格是 12px 金，实现是奶油色，悬停才金。
- 页脚「夜间」规格 gold-dim 9px，实现灰 11px。
- `--font-serif` 把 `Noto Serif SC` 写在 `Archive Serif Fallback` 前，Linux 上碑偏厚，违「不要把 Songti SC 指到 Noto」。
- 夜间圆印仍是浅色块 + 赤陶，像白日贴纸。
- 共现标签无「还可收窄」的句子。
- 货架顶栏条数与 `#shelf-status` 重复。
- DESIGN.md YAML 字号阶比正文窄，后续 `/document` 不修 sidecar，检测器会一直打 11px / 13px。

## Questions to Consider

- 提问时两字碑是否应该让位？题签时刻和命中时刻要不要两套构图？
- 唯一题名时，Enter 打开是不是比进货架更像「拾光」？
- 金色叉要多显眼，才仍是档案纸而不是胶囊？
- 七词是身份还是导航？7 个无框词是不是在要求用户先懂「这是标签」？
- 圆印里的赤陶方，是不是在讲另一个故事？
