## Design Specificity Verdict

**LLM assessment：** 为这个产品写的，不是品类换皮。浅档案纸、两字碑、一根金线提问互相咬合：卡片只在货架、Logo 回厅、夜间只换 `data-paper`、碑题 400 不 bold。把文案换成「Acme Cloud」界面会立刻散掉。不该因为拒绝仪表盘、厅内卡片网格或柠绿主题而扣分——那是 brief 边界。

会把它从「私人藏书厅」拉回「普通静态页」的，是执行裂缝而不是克制：货架丢掉签名提问线；按钮漏继承字体；厅列表把长 URL 折成一团。气质是作者的，零件漏继承。

**Deterministic scan：** CLI `detect.mjs --json index.html` 退出 0、JSON `[]`，但 stderr 标明 **DEGRADED**：htmlparser2 / css-select / css-tree / domutils 不可用，退回正则，自定义属性、选择器匹配、计算对比度都没跑。空集是欠报，不是健康证明。

页内检测器（独立 Playwright 会话，厅 `/`、货架 `/shelf`、`/shelf?q=vite`）才是有效 B 证据：

- 厅：约 15 个 anti-pattern，20 条 LOG
- 全库货架：64 条 LOG（含 46 次 `low-contrast`）
- 约束货架：22 条 LOG

与 A 重合、应保留的命中：白日纸上 `#9aa0a8` 对 `#eef0f2` / `#f6f7f9` 约 2.3–2.5:1（页脚、键位、卡片 URL）；9–10px 印戳与「夜间」；Linux 上按钮被算成 Arial（源码未 `font: inherit`，半真）。

**应视为误报或 brief 内意图：** `hero-eyebrow-chip`（BIBLIOTHECA 是厅面眉题，DESIGN.md 阅读顺序里就有；货架上扫到它是因为隐藏的 `#view-hall` 仍在 DOM）；`wide-tracking` 印戳字距是 Archive Paper 身份；`dark-glow` 命中的是圆印 1px 金环，不是柔光；footer / 夜间成对翻倍是厅架双页脚；`overused-font: arial` 把系统无衬线栈算成主字体。二次 `serialize` 才出现的 `text-occlusion` 是 overlay 标签盖在 `.card-desc` 上。

**Visual overlays：** 注入成功，检测器在页内跑过（货架 115 个 overlay 节点，约束架 31 个）。会话随后关闭，live-server 已停，**你的浏览器里没有残留 [Human] 叠加层**。证据来自该会话的控制台与节点计数，不是当前桌面上的可见高亮。

## Overall Impression

厅面桌面几乎兑现了北星：碑落下、金线从左生长、夜间仍是同一张纸。真正干活的货架却把提问线收成一根约 180px 的短桩，元数据对比不够，卡片和标签还嵌在同一热区里。最大机会不是更大胆，而是让货架继续用那根金线，并让「打开」和「收窄」不再抢同一块拇指。

## What's Working

1. **厅面桌面是有作者的纪念碑。** 阅读顺序与 DESIGN 一致：圆印 + 字标 / 金点 + 印戳 → 眉题 → 两字碑 → 耳语 → 底边提问 → 键位 → 七词 → 页脚换纸。1440 一屏不滚。夜间同一 DOM，theme-color 跟纸走。
2. **货架卡片材料对了。** sheet 落在档案纸上，圆角 2px，发丝边，悬停改金边不抬起；空描述不占位；网格 1 / 2 / 3 列；星尘在货架关掉。
3. **知道名字时，维护者路径很短。** 厅自动聚焦，键入即时索引，未选中回车进货架，选中题名开外链，七词和卡片标签可加精确约束，Logo 回厅。

## Priority Issues

### [P1] 货架提问线不是那根金线

- **Why it matters：** 高峰在厅，工作在货架。`.shelf-field` 不是 flex 行，`.search-input` 的 `flex: 1` 落空，固有宽度约 20ch（实机 ~180px）；没有 `.grow-line`，`outline: none`，还是 `type=search` 带 UA 清除钮。签名交互在真正筛选的房间里缺席，焦点几乎不可见。
- **Fix：** 货架复用厅的 `search-row`：全宽、`type="text"`、金线从左生长、可选同一圆钮；焦点只靠金线，不要原生 search chrome。
- **Suggested command：** `/impeccable layout`

### [P1] 卡片是链接，标签是嵌在里面的按钮

- **Why it matters：** `<a class="bookmark-card">` 内再塞 `<button class="card-tag">`。Casey 点「文档」极易误开 MDN；Sam 在一张卡里遇到两个控件；这是主任务「打开 **或** 收窄」的结构冲突。
- **Fix：** 卡是容器。标题/URL 才是外链；标签放在 `<a>` 外，或独立 chip 行。不要靠 `stopPropagation` 维持非法嵌套。
- **Suggested command：** `/impeccable harden`

### [P1] 白日纸上，元数据与开关对比不够

- **Why it matters：** 检测器在全库货架打出 46 次 `low-contrast`。ash-deep `#9aa0a8` 对纸 `#eef0f2` 约 2.3:1，对卡片 sheet 约 2.5:1——页脚、键位、厅分组名、卡片 URL 都在这档。金作字约 3.3:1；「夜间」9px gold-dim 约 2.8:1。选中态、换纸、URL 都是「还找不找得到」的字。夜间整体好转，不能当白日的借口。
- **Fix：** 白日把 URL / 页脚 / 键位收到接近 ash（`#5d646d` 一带，已过 5:1）；金继续给线和环，少给 9px 字；开关热区至少 24×24，字可仍克制。不许改金色相。
- **Suggested command：** `/impeccable audit`

### [P1] 提问进行时选择面过大，长 URL 拆掉题名索引

- **Why it matters：** 空厅「一根线」成立。一打字：碑、键位、最多 7 行索引、7 个七词同时在。长 URL 把厅行折成 2–3 行（夹具 GitHub 源码地址实机 50–63px 高）。选中后点放大镜会开站点，与「检索书签」相反。七词作为品牌数字可以留在空厅；输入后不退场才是负担。
- **Fix：** 有查询时收起或降对比七词；`.hall-item-meta` 单行 ellipsis；Escape 清除选中；检索钮在有选中时仍应进货架，开链留给回车/点行。
- **Suggested command：** `/impeccable distill`

### [P2] 热区、跳过链接、顶栏条数、手机构图

- **Why it matters：** 「夜间」约 22×13；卡片标签高 15px；跳过链接聚焦时盖住字标，且厅 `search.focus()` 让它几乎当不成第一站；顶栏永远「44 站点」；手机轨道圆切过「光」；稀疏货架页脚停在视口中部。合在一起让克制读成没做完。
- **Fix：** 透明加大换纸热区；skip 避开 sticky header；顶栏改成当前命中或删掉只留状态句；手机缩小/隐藏 `.orbit`；`button { font: inherit; }`；货架主列把页脚送到视口底。
- **Suggested command：** `/impeccable adapt`

## Persona Red Flags

**Alex（维护者 / 键盘）：** 键入 `vite` → ↓ → ↵ 开 Vite，很快；一旦选中，放大镜不再检索，也没有 Escape。空回车是 44 张无索引墙。点卡内标签才能按卷收束，而标签嵌在外链里。

**Sam（键盘 / 读屏）：** 厅列表无 listbox / `aria-activedescendant`。`#q` 与 `#shelf-q` 关掉 outline，货架没有替代指示。卡片 `aria-label="打开 …"` 加内部按钮「文档」双重朗读。`#shelf-status` 与 `#shelf-results` 双 `aria-live`。纸切换 live-note 是加分，9px 开关是对比和热区双重失败。

**Casey（390 宽拇指）：** 碑约 51px，轨道压「光」。七词第二行孤零零「未分类」。货架提问 180px 被裁，没有圆钮。卡片标签 15px 嵌在整卡链接里——误开外链的主因。「夜间」在右下几乎不是拇指控件。

## Minor Observations

- 认知负荷清单 5/8 失败（Single focus / Chunking / One thing at a time / Minimal choices / Working memory）。空厅选择其实是提问、七词、空回车；七词 7 个是 brief 允许的品牌数字，不要当成要删掉七词。失败集中在「输入之后」和「全库货架」。
- `meta color-scheme` 写死 `light`；夜间 UA 控件可能不跟纸。
- 夜间 `<kbd>` 边框是黑 8% 透明，键帽轮廓消失。
- 约束芯片整颗是删除，没有「移除」动词。
- 目录里 Tailwind 条目描述写「当前项目的样式基础」，与 PRODUCT（原生 TS、不用 daisyUI）矛盾——信任问题，不是布局。
- 星尘白日几乎看不见；`prefers-reduced-motion` 有停动画，本次未切系统设置实机验证。
- 搜索提交钮悬停金尘光晕只给那一颗圆钮，没有滥铺——对。
