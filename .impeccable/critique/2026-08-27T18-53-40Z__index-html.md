## Design Specificity Verdict

**LLM assessment：** 为七卷拾光写的，不是品类换皮。浅档案纸、两字碑、一根金线提问互相咬合：卡片只在货架、Logo 回厅、夜间只换 `data-paper`、碑题 400 不 bold。把文案换成「Acme Cloud」界面会立刻散掉。不该因为拒绝仪表盘、厅内卡片网格或柠绿主题而扣分——那是 brief 边界。

会把它从「私人藏书厅」拉回「普通静态页」的，是货架在少命中/空命中时被撑开，以及厅内无匹配时整组快捷入口被撤走。气质是作者的；失败态和键盘选中漏继承。

**Deterministic scan：** CLI `detect.mjs --json index.html` 退出 0、JSON `[]`，但 **DEGRADED**：htmlparser2 / css-select / css-tree / domutils 不可用，退回正则，自定义属性、选择器匹配、计算对比度都没跑。空集是欠报。

`detect.mjs --json index.html src` 退出 2，**15** 条，全部 `design-system-font-size` advisory，均在 `src/styles.css`。页内检测器（独立 Playwright 会话 `critique-b`，厅 `/`、全库 `/shelf`、`/shelf?q=vite`、空命中、夜间厅）才是有效 B 证据：

- 厅：7 条 overlay（eyebrow + tracking + 金尘光晕）
- 全库货架：14 条 overlay，含 7 次 `undersized-ui-text`（组名 `文档 · 11` 等 10px）
- 约束货架：7 条 overlay，无 undersized
- 空命中：8 条 overlay
- 夜间厅：与白日厅同一套规则；**无 contrast 命中**

与 A 重合、应保留的命中：全库货架组名 10px（视觉上不像分块，即使 YAML label 是 10px）。

**应视为误报或 brief 内意图：** CLI 的 11px / 13px / 12px（DESIGN 正文已写 Label 9–11px、耳语 13px、text-action 12px）；`hero-eyebrow-chip`（BIBLIOTHECA 是厅面眉题；货架上扫到它是因为隐藏的 `#view-hall` 仍在 DOM）；`wide-tracking` 印戳/耳语/芯片字距是 Archive Paper 身份；`dark-glow` 命中的是检索圆钮悬停金尘，brief 明确只给那一颗圆钮。footer 成对翻倍是厅架双页脚。

**Visual overlays：** 注入在 **headless** Playwright 会话内成功（live-server `:8400`，厅 7 / 全库 14 / 约束 7 / 空命中 8 个 overlay 节点）。会话随后关闭，live-server 已停，**你的浏览器里没有残留 [Human] 叠加层**。证据来自该会话的控制台与节点计数，不是当前桌面上的可见高亮。

## Overall Impression

厅面桌面几乎兑现北星：碑落下、金线从左生长、夜间仍是同一张纸。上一轮的货架短桩、卡片嵌按钮、「未分类」、双 aria-live、44 张无索引墙，这轮评审里不再构成 P1。真正还在伤任务的，是货架用 `flex: 1` 把少命中和空命中撑满一屏，以及厅内打错词时整座快捷入口被收走、键盘选中几乎看不见。最大机会不是更大胆，而是让货架在 0–2 条时仍像一张纸，让厅在无匹配时仍能说话。

## What's Working

1. **厅面桌面是有作者的纪念碑。** 阅读顺序与 DESIGN 一致。1440 一屏不滚（空提问时）。夜间同一 DOM，theme-color 跟纸走。空回车进全部货架。
2. **双通道检索的骨架是对的。** 七词 → 精确标签；提问 → `q`；可叠；约束可叉；Logo 回厅；URL 可分享。卡片名称/URL 拆开，标签在 `<a>` 外。
3. **读屏骨架补上了。** 厅 combobox / listbox / `aria-activedescendant`；选项 `tabIndex=-1`；货架只留一处 `aria-live`；`color-scheme` 支持 light dark。切纸有 `#live-note`。

## Priority Issues

### [P1] 少命中与空命中被结果网格撑满视口

- **Why it matters：** `.shelf .results { flex: 1 }` 在 `min-height: 100svh` 的纵 flex 里把网格拉满。1–2 条命中时卡片被撑到约半屏；空命中把「没有匹配的书签」、说明、「清除约束」拆成三块孤岛。克制读成没做完。
- **Fix：** 结果网格 `align-items: start`；`.state-panel` 不要吃剩余高度。页脚用 margin 推到底，不要让卡片去填。少命中卡片接近内容高度；空命中收成紧凑一块。
- **Suggested command：** `/impeccable layout`

### [P1] 厅内无命中失声

- **Why it matters：** 一打字就藏七词；无建议则索引也 hidden。打错词时厅变成一座无索引的碑，没有「厅内无题名」，维护者只能猜该按检索钮。直接拉长「尽快找到」。
- **Fix：** 有提问且列表为空时，在索引位留一行耳语（如「厅内无题名。回车到货架上看。」）；七词可降对比但不要整组消失；live 同步一句。
- **Suggested command：** `/impeccable clarify`

### [P1] 厅内键盘选中几乎不可见，Enter 双语义因此危险

- **Why it matters：** DESIGN 写「悬停或选中变金」。实现是 `.hall-item.is-active { color: cream }`。灰改墨，14px 行对比太弱。未选中 Enter = 货架，选中题名 Enter = 开外链。键盘主路径会误开世界。
- **Fix：** 选中行用金（标题或左侧发丝），保留 `aria-activedescendant`。选中态必须扫一眼就知道。
- **Suggested command：** `/impeccable polish`

### [P2] 全部货架的分组只写在 10px 标签上

- **Why it matters：** 按首标分块已进 DOM（文档 · 11 … 存档 · 2），但组名复用厅内 `hall-group-label`，桌面三列里几乎是装饰；不 sticky；390 宽滚过顶栏后像游离残片。页内检测器在全库货架打出 7 次 `undersized-ui-text`（10px 组名）。YAML label 是 10px，所以这不是「字小于 token」，而是「分块索引用了厅内耳语级」。
- **Fix：** 组标题升到可扫读层级；至少 sticky 在顶栏下。可选：提问下用与七词同形的跳组，不要只能靠滚。
- **Suggested command：** `/impeccable layout`

### [P2] 约束、共现、卡片标签、七词认不出四种动作

- **Why it matters：** 全部无填充无描边。约束靠一个金色 `×`；共现与七词同形；卡片标签像元数据。顶栏「N 个站点」和状态句「找到 N 个 / 全部站点」重复。已选标签点了静默。
- **Fix：** 约束 `aria-label="移除提问 …"` / `移除标签 …`；共现加极淡说明或保持但不要和移除芯片撞形。已选标签在卡片上不要再当按钮。条数只留一处。
- **Suggested command：** `/impeccable clarify`

## Persona Red Flags

**Alex（维护者 / 键盘）：** 键入 `vite` 必须再 ↓ 才选中；选中几乎看不见，Enter 可能开外链。货架无题名索引，二次收窄靠改提问或点不像按钮的词。`/` 聚焦且不把 `/` 打进框——这条要保护。

**Sam（键盘 / 读屏）：** Combobox 骨架正确。货架无可见 `h1`（厅碑在 `hidden` 里）；44 张卡全是 `h2`，组名是 `<p>`，无法按组跳。约束可读名可能带 `×`。卡片 `aria-label="打开 …"` 不说明新标签页。空命中面板无 `role="alert"`（加载失败才有）。

**Casey（390 宽拇指）：** 七词末词「存档」单独一行。厅索引行高约 29px，点题名会新开外链。全部货架竖滚近整卷，提问行不黏，组与组几乎没有停顿。夜间钮热区 44px 对，但混在页脚印戳里。

## Minor Observations

- 认知负荷清单 6/8 失败（Single focus / Chunking / Grouping / Visual hierarchy / One thing at a time / Working memory）。空厅选择其实是提问、七词、空回车，七词 7 个是 brief 允许的品牌数字。失败集中在「输入之后的失声」和「货架少/空/长三种状态」。
- 白日金对纸约 3.3:1，作发丝刚过 UI 3:1，不能当 11px 正文。页内检测器本轮 **没有** contrast 命中（CLI 对比度因 DEGRADED 没跑）。
- `.search-input` 关掉 outline，焦点全交给金线；圆钮上的 `:focus-visible` 方框套圆。
- 耳语 13px + 0.18em 字距，中文被撑疏。
- Brief 页脚切纸 9px 金暗色；实现 11px 灰，hover 才金。`text-action` 默认是墨，不是金。
- 桌面打满约七行索引时，页脚被顶出 900px 视口——「厅内一屏」只在空提问时成立。
- 长 URL `overflow-wrap: anywhere` 会在查询串中间切开。
- 星尘货架关掉；`prefers-reduced-motion` 有停动画。
