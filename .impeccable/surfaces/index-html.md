# 首页

## Scope and mode

Visitor mode: Operate。
Surface: 书签门户首页（`/` 搜索厅与 `/shelf` 货架，同一 `index.html`）。

## Audience and job

维护者（及只读访客）打开后尽快找到并打开一个资源站。

## Task

在搜索厅提问或点七词，然后在货架打开书签 URL。空回车进入全部货架；有提问词或标签约束进入命中集合。货架结果顶列出本次结果相关标签，点标签切换精确约束，卡片不再按首个标签分块插标题。搜索覆盖名称、描述和标签，不搜 URL。提问词是整句模糊匹配，标签是精确约束，两者可叠加。

厅内：空厅不自动聚焦。`/` 或「跳到提问」聚焦提问；方向键选择题名或匹配标签；选中题名，或无选中且唯一题名时，回车打开 URL；选中标签、点七词，或提问词与匹配标签同名，则带该标签进货架；空提交、多条命中未选中，仍进货架。厅内无匹配时耳语说明「没有这道题。回车看全部货架」，回车进入无约束货架。Logo 回厅时清空提问并收起索引。货架不设「已约束」行；提问词在提问框里改，点结果顶或卡片标签则切换精确约束。提问时碑、眉题、耳语留在原位，不缩小碑；厅进入 `is-asking` 时七词收起，提示让位给索引。触控或窄屏用中文提示替代键位，不隐藏空厅提示。货架顶栏与提问行吸顶。门户源失败不复用货架提问行。

## Constraints

- 规模上限约 2,000 条，浏览器原生分批渲染。
- 卡片必显名称和 URL。题名一行、描述两行、网址一行裁切；空描述仍占两行，使卡片同高。
- 白日/夜间同一 DOM、同一阅读顺序；用 `data-paper` 换色板。
- 标签从条目汇总；七词按引用次数最多取七个，不编造。
- 覆盖：门户源加载失败、空目录、无命中、长 URL、缺描述、键盘焦点、`prefers-reduced-motion`。
- 不做：账号或写入后端、首页编辑、大胆/柠绿主题、用 Logo 切主题、厅内卡片网格。

厅面文案与书签只改 `public/portal.json`。

## Direction

Archive Paper，code-first。搜索厅是一屏题签：页头（圆印 + 字标 / 金点 + 印戳）→ 眉题 → 两字碑 → 两行耳语 → 提问线 → 键位或触控提示 → 输入后的题名索引（最多约七行，无卡片）→ 七词 → 页脚。提问时碑不收起，七词收起。货架不复制碑：Logo 回厅、提问线、条数、本次结果标签、卡片网格（移动 1 列，`768px` 起 2 列，`1024px` 起 3 列）；顶栏与提问吸顶。

Signature interaction：提问是底边线加圆钮，不是输入盒。厅内聚焦时金线从左生长；货架共用通栏底边与圆钮，聚焦只改线色，不生长。空提交进入全部货架。

## Memorable moment

两字碑落下，一根金线等你提问。进货架后碑消失，只剩安静卡片。

## Unresolved

第一版不做大胆主题。厅内眉题是现有厅面文案，不是可复用零件。
