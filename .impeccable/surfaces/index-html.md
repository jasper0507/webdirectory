# 首页

## Scope and mode

Visitor mode: Operate。
Surface: 书签门户首页（`/` 搜索厅与 `/shelf` 货架，同一 `index.html`）。

## Audience and job

维护者（及只读访客）打开后尽快找到并打开一个资源站。

## Task

在搜索厅提问或点七词，然后在货架打开书签 URL。空回车进入全部货架（按首个标签分块）；有提问词或标签约束进入命中集合。搜索覆盖名称、URL、描述和标签。提问词是全文检索，标签是精确约束，两者可叠加。

厅内：`/` 聚焦提问；方向键选择题名或匹配标签；未选中回车进货架；选中题名回车打开 URL；选中标签或点七词则带该标签进货架。货架上可叉掉提问词与已选标签，点共现标签或卡片标签则追加精确约束。Logo 回厅。

## Constraints

- 规模上限约 2,000 条，浏览器原生分批渲染。
- 卡片必显名称和 URL；空描述不占位。
- 白日/夜间同一 DOM、同一阅读顺序；用 `data-paper` 换色板。
- 标签从条目汇总；七词按引用次数最多取七个，不编造。
- 覆盖：门户源加载失败、空目录、无命中、长 URL、缺描述、键盘焦点、`prefers-reduced-motion`。
- 不做：账号或写入后端、首页编辑、大胆/柠绿主题、用 Logo 切主题、厅内卡片网格。

厅面文案与书签只改 `public/portal.json`。

## Direction

Archive Paper，code-first。空厅是一屏题签：页头（圆印 + 字标 / 金点 + 印戳）→ 眉题 → 两字碑 → 两行耳语 → 提问线 → 键位提示 → 七词 → 页脚。提问后碑让位：页头 → 提问线 → 题名索引（最多约七行，无卡片，锁在线与脚之间）→ 七词 → 页脚。货架不复制碑：Logo 回厅、提问线、可叉约束、共现标签、条数、卡片网格（移动 1 列，`768px` 起 2 列，`1024px` 起 3 列）。

Signature interaction：提问是底边线加圆钮，不是输入盒。厅内聚焦时金线从左生长；货架共用通栏底边与圆钮，聚焦只改线色，不生长。空提交进入全部货架。

## Memorable moment

两字碑落下，一根金线等你提问。一提问，碑让位，索引锁在线与脚之间。进货架后碑消失，只剩安静卡片。
