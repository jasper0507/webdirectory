# 收录扩展直接提交到默认分支

收录扩展要把条目草稿写进门户源。复制片段仍要维护者自己提交；开 PR 还要多点一次合并。当前要消的就是「改 JSON 再推送」整段摩擦，fork 的维护者同样如此。因此扩展用维护者自己的 GitHub 凭证，把对门户源的追加直接提交到该仓库的默认分支；公开门户仍然没有写入后端，站点身份仍不由扩展改写。这有意承担 ADR 0001/0007 想避开的密钥与「填完即上线」：密钥只存在扩展里，上线以这次 GitHub 提交为准。目标仓库由选项中的 owner 与 repo 指定，路径固定为 `public/portal.json`，分支取该仓库默认分支。凭证是仅对该仓 Contents 授权的细粒度 PAT，存在浏览器本地、不同步。提交时 SHA 过期则失败并保留条目草稿，不自动合并、不整文件覆盖。

不采用剪贴板/下载（摩擦剩一半），也不开 PR（多一次合并，解不掉你要消的那下）。不做浏览器书签树整份覆盖。
